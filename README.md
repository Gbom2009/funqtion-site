# funqtion-site

The Team Funqtion website — a Dutch allround DJ duo from Aarle-Rixtel.

**Live:** https://gbom2009.github.io/funqtion-site/

## Status

Holding page only. The full six-page site is being built against the brief in the
private `Gbom2009/FUNQTION` repository, branch `funqtion-site-brief`:

- `funqtion/START-HERE.md` — reading order
- `funqtion/BUILD-BRIEF.md` — the specification
- `funqtion/CONTENT.md` — all Dutch copy, verbatim
- `funqtion-assets/` — logo and photos

## Stack

Plain HTML, CSS and JavaScript. No framework, no bundler, no build step. The only
external requests are Google Fonts, and later a Canva embed and Spotify embeds.

## Design

Near-black monochrome, monospaced type, a single orange accent (`#f68712`), a
twelve-column grid with zero gap, hairline rules and corner-bracket buttons, under an
animated film grain. See the brief for the full system.
